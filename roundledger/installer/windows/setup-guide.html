RoundLedger setup

Version —. The files are installed. Chrome requires you to add this extension yourself. It takes about a minute.

  1. Open Chrome's extensions page. Copy this address, paste it into Chrome's address bar and press Enter (Chrome does not allow web pages to open it directly).
    chrome://extensions
  2. Turn on "Developer mode" with the switch in the top-right corner of that page.
  3. Click "Load unpacked" and select this folder:
    %LOCALAPPDATA%\RoundLedger\extension

    Tip: in the folder picker, paste the path into the address bar at the top and press Enter, then click "Select Folder".

  4. Pin RoundLedger. Click the puzzle-piece icon in Chrome's toolbar, then the pin next to RoundLedger. Click the RoundLedger icon to open its side panel.
  5. Sign in or create an account in the side panel, then start your free trial or enter your activation code.
  6. Allow access to the game page when the panel asks, then reload the game tab. RoundLedger only reads round results; it never places bets.
Chrome may show "Disable developer mode extensions" when it starts. Choose Keep or close the message. This is Chrome's standard reminder for extensions not installed from the Chrome Web Store.

Troubleshooting

There is no "Developer mode" switch or "Load unpacked" button

Your Chrome is managed by an organization (a work or school device) and policy blocks unpacked extensions. RoundLedger cannot be installed on this browser. Use a personal computer or ask your administrator.

"Manifest file is missing or unreadable"

You selected the wrong folder. Select the extension folder itself (the one containing manifest.json), not its parent.

Updating to a new version

Run the new installer. Then open chrome://extensions and click the circular reload arrow on the RoundLedger card, or restart Chrome. Your sign-in and history are kept.

Checking the installed files

In the RoundLedger folder, right-click verify-files.ps1 and choose "Run with PowerShell". It compares every file with the published SHA-256 checksums.

Uninstalling

Click Remove on the RoundLedger card in chrome://extensions, then uninstall RoundLedger from Windows Settings → Apps.

Results in crash games are random. RoundLedger describes past rounds and does not predict future ones. Gamble only what you can afford to lose. Help: begambleaware.org
