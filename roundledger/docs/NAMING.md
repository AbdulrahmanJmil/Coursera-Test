# Product name

**Working name: RoundLedger** (provisional). It says what the product honestly does, keeping a ledger
of rounds, without promising wins or predictions. It is short and works as a monospace wordmark.

| Candidate | Why | Concern |
|---|---|---|
| **RoundLedger** (chosen) | Descriptive, neutral, matches the "record and describe" scope | "Ledger" is also a well-known crypto hardware-wallet brand in a different class |
| Tallyline | Short, distinctive, "tally" = counting rounds | Less obviously about games |
| CrashLog | Very clear | "Crash" reads as software failure; generic |
| Roundwise | Friendly | "-wise" implies insight/advice the product does not give |
| Crash Game Companion | The original working name | Generic, hard to protect |

Names implying prediction, signals, wins or AI edge (e.g. "Crash Predict AI") were rejected because they
would misdescribe the product.

**Checks done:** basic web searches for "RoundLedger" and "Tallyline" found no software product with
those names (October 2026). **No trademark search was done.** Before commercial launch, have a
trademark attorney search the relevant classes (9 and 42) and markets, and check domain and
social-handle availability.
